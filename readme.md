# El estado del arte y comparación de los modelos monoculares

En este presente repositorio se presentan 6 modelos monoculares, los cuales se realizo una prueba de uso, los pasos detallados se registran en cada cuadernillo de manera detallada.

Los modelos usados fueron:
* Depth Anything V2
* Depth pro(apple)
* Marigold
* Metric3D
* MiDaSv3.1
